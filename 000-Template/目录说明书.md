# Folio 目录说明书

Folio 使用 PARA 思路组织文稿。数字前缀用于保持目录顺序，英文 type 是 YAML 中稳定的文稿类别。

| 目录 | PARA 含义 | 对应 type | 存放内容 |
|---|---|---|---|
| 收集箱 | Inbox，临时入口 | `spark` 及暂未归类文稿 | 念头、Ctrl+N 新建文稿、待继续编辑内容 |
| 000-模板 | Template，模板 | — | 本系统的 Markdown YAML 骨架和本说明书 |
| 100-项目 | Projects，有明确目标的工作 | — | 项目类父目录 |
| 110-项目 | Project，项目 | `project` | 有目标、进度和下一步的项目或计划 |
| 120-会议 | Meeting，会议 | `meeting` | 项目会议、决议与待办 |
| 200-领域 | Areas，长期责任领域 | — | 每日维护和周期复盘的父目录 |
| 210-每日 | Daily，每日记录 | `daily` | 每日反省、工作、健康与明日安排 |
| 220-复盘 | Review，阶段总结 | `review` | 周回顾和阶段性总结 |
| 300-资源 | Resources，可复用资料 | — | 视频、读书、收藏和发布内容的父目录 |
| 310-视频 | Video，视频资料 | `video` | 单集笔记和视频系列目录 |
| 320-读书 | Literature，读书与长文 | `literature` | 主张、摘录和反驳 |
| 330-收藏 | Clip，外部收藏 | `clip` | 别人的资料、收藏原因和下一步 |
| 340-publish | Publish，分享与发布 | `tutorial` | 技巧备忘和可供他人执行的成稿 |
| 400-归档 | Archives，已完成内容 | — | 已结束但需要保留的内容 |
| 999-未分类 | Uncategorized，杂项与软删除 | — | 杂项、旧自由文稿和已软删除文稿 |

## 新建规则

- 在具体 type 目录中右键或使用 Menu 键新建，只显示该目录对应的模板，文稿留在当前目录。
- 使用 `Ctrl+N` 快速新建时，先选择 type，再选择具体模板；新文稿先进入收集箱。浏览器若保留 `Ctrl+N` 用于新窗口，可使用 `Alt+N` 或侧栏顶部“+”按钮。
- `spark` 正式存放在收集箱，不参加自动归类。

## 归类规则

- “结束本次写作”或 `Ctrl+Shift+E` 会检查本轮新建或真正修改过的收集箱文稿。
- 自动归类到 type 对应目录不需要超级密码。
- 手动移动、创建文件夹、重命名文稿、删除文稿和删除系统预设目录需要超级密码。
- 删除文稿是软删除：文稿移动到 999-未分类，并标记 `status: trashed`；永久删除功能留待后续实现。
